# Global Visa and Migration

Website for Global Visa and Migration — visa and migration services for Canada, Australia, the UK and New Zealand.

## Running locally

Requires Node.js and npm.

```sh
# Install dependencies
npm i

# Start the development server (http://localhost:8080)
npm run dev

# Build for production (output in dist/)
npm run build
```

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
